# Fennec 1.0.1

- Keeps your Automatic repair choice after an update while the approved helper starts up.
- Prevents overlapping helper recovery during relaunch.
- Makes Check for Updates available again after cancelling an update offer.

Requires macOS 14.2 or later on Apple silicon. Updates are checked, downloaded,
and installed only when you choose. If macOS needs helper approval again,
Fennec uses Ask me first until you enable it.
